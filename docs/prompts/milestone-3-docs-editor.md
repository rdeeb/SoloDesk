# Milestone 3 — Docs and Editor

Build Milestone 3 for SoloDesk.

## Goal

Implement standalone docs, project docs, and a Tiptap editor with slash commands.

## Implement

1. Docs list page.
2. Standalone docs flat list.
3. Project docs tab/page.
4. Doc editor page.
5. Tiptap editor with text-focused blocks only.
6. Slash command menu for paragraph, headings, bullet list, numbered list, quote, code block, divider.
7. Autosave doc title and content.
8. Recent docs support.
9. Soft delete docs.

## Acceptance criteria

- Users can create standalone docs.
- Users can create docs inside projects.
- Editor content persists after refresh.
- Slash commands work for v1 block types.
- Deleted docs move to trash.

# Milestone 6 — Import/Export, Trash, and Polish

Build Milestone 6 for SoloDesk.

## Goal

Make the app safe, portable, and portfolio-ready.

## Implement

1. Export JSON backup.
2. Import JSON backup.
3. Validate backup shape before import.
4. Show import preview counts.
5. Replace all current data after explicit confirmation.
6. Trash page.
7. Restore soft-deleted records.
8. Permanently delete individual records.
9. Empty trash.
10. Dashboard filters.
11. Empty states.
12. Responsive layout polish.
13. README updates.

## Acceptance criteria

- Export downloads a valid SoloDesk backup JSON file.
- Import rejects invalid JSON.
- Import shows preview counts before replacing data.
- Import replaces all current data only after confirmation.
- Trash page shows soft-deleted records.
- Users can restore or permanently delete trashed items.
- App feels portfolio-ready on desktop and tablet widths.

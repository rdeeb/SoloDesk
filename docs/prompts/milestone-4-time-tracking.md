# Milestone 4 — Time Tracking

Build Milestone 4 for SoloDesk.

## Goal

Implement manual time tracking.

## Implement

1. Time entry model and repository.
2. Global time page.
3. Project time page.
4. Client time summary through linked projects.
5. Time entry form.
6. Project is required.
7. Task is optional.
8. Duration accepts hours/minutes and decimal hours.
9. Store duration as minutes.
10. Billable flag.
11. Hourly rate snapshot.
12. Dashboard billable summaries.

## Acceptance criteria

- Users can add manual time entries.
- Time entries require a project.
- Decimal and hours/minutes inputs both work.
- Billable totals calculate correctly.
- Time entries can be soft-deleted.
